Q&A 確認済みルール (3件)
Q3 認証・本人確認 ✓ 確定 優先度: 高
新規登録時、Googleログインだけでなく、LINEやAppleログインも必要ですか？…
SNSログインなし（メールのみ）。LINEログインは別途確認待ち。Google/Apple/Facebookは対象外で確定。

SCR-020
Login
ログイン / Đăng nhập
JA
VI
画面の目的
既存ユーザーの認証エントリポイント。セッションを確立してアプリ内に誘導する。
ログインロジック
1
Email + Password — SNSログイン（Google / LINEなど）は使用しない。
2
Remember me — チェック時はトークンを30日間保持。デフォルトはOFF。
3
認証成功 → セッション確立 → プロフィール設定済みの場合はSCR-060へ、未完了はSCR-030へ。
!
失敗時 — 5回連続失敗でアカウントを一時ロック（30分）。ロック中は再試行不可のメッセージを表示。
パスワードリセット
→
「パスワードを忘れた方」→ SCR-025 メール入力 → SCR-026 送信完了 → メールリンク → SCR-027 新パスワード → SCR-028 完了 → SCR-020 再ログイン。
!
電話番号不要。存在しないメールでも「送信しました」と表示。
注意事項
⚠ パスワードはフロントエンドでハッシュ化せず、HTTPS通信を必須とする。
新規登録はこの画面にリンクあり → SCR-021へ。
Mục đích
Entry point cho user đã có tài khoản. Xác thực session và điều hướng vào app.
Logic đăng nhập
1
Email + Password — không dùng SNS login (Google / LINE / Apple đều không áp dụng).
2
Quên mật khẩu → gửi link reset qua email, không cần nhập số điện thoại.
3
Đăng nhập thành công → SCR-060 Home. Profile chưa hoàn thiện → redirect SCR-030.
Chuyển màn
✓
Đăng nhập thành công → SCR-060 Home
?
Chưa có tài khoản → SCR-021 Register
✉
Quên mật khẩu → SCR-025 → 026 → 027 → 028 → 020
